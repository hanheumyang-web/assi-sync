# 실제 서버에 붙어서 도는 시험

`test/*.test.js` 는 서버 없이 도는 시험이다. 여기 있는 것은 **실제 assifolio.com 에
로그인된 계정으로** 업로드·삭제까지 진짜로 해본다.

## 왜 따로 두나

가짜 서버로는 못 잡는 것들이 있다.
`deleteProject` 가 완전 삭제인지 휴지통행인지, 업로드한 파일이 정말 되돌아오는지,
폴더를 새로 팠을 때 웹이 안 지워지는지 — 이런 건 진짜로 해봐야 안다.

## 돌리는 법

싱크앱에 로그인이 되어 있어야 한다 (토큰을 앱 설정에서 읽는다).

```
node test/live/new-folder.live.js
```

⚠️ 시험용 프로젝트(`ZZ_새폴더_`)를 계정에 만들었다 지운다.
   시험 폴더는 바탕화면에 `_시험 …` 이름으로 만들었다 지운다.
   기존 자료는 건드리지 않는다 — 이름이 `ZZ_` 로 시작하지 않는 것은 절대 손대지 않는다.

## new-folder.live.js — 무엇을 보는가

기존 사용자가 **폴더를 새로 파서 다시 동기화하는 경우**.
2026-09-07 테스터가 겪은 상황과 가장 가깝다.

1. 옛 폴더에서 평범하게 올려 둔다 (기존 사용자 상태)
2. 빈 새 폴더로 옮긴다 → 웹이 안 지워지는지, 헛된 삭제 확인이 안 뜨는지
3. 사진을 복사해 온다 → 다시 올라가 두 배가 되지 않는지
4. 웹 삭제 신호 → 신원 확인이 돌고 되돌릴 수 있는지
